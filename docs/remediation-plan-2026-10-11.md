## 批次 1 · v1.6.0 —— P0 安全（预估 1.5h）

1. **身份防劫持**：`identities` 首写为准（不覆盖）+ 归一化姓名匹配；admin 可修正身份（防笔误锁死）。执行前先审计线上 identities 现状
2. **PIN 二级验证**：4 位 PIN（scrypt/SHA-256+salt 存 `pin_hash`）；**首次使用设置**，之后认领 / 领取查询 / 出库 / 兑换需校验；admin 可重置。登记（report）仅要求姓名匹配、免 PIN（保低摩擦）
3. **兑换身份校验**：redeem 需学号+姓名（+PIN）
4. **认领防刷**：活跃认领 ≤3、每日 ≤5（阈值可在后台调，见批次 4）
5. **下线领取码**：claims 不再发码；券面改提示；fulfill 删码通道；verifyPickup 删除；`remediation` 保留 schema 列（不删线上列）
6. **后台加固**：失败 ≥5/IP/10min → 429（口令值不变）
7. **物品码熵**：`LF-YYYY-<crypto base36×4>`
8. **R2 绑定**：建桶 + `r2_buckets` 绑定 + 出库存证启用；旧 photo_path 无对象者回退占位

**新增测试**：不覆盖改名 / 姓名不符 403 / PIN 校验与重置 / 无 PIN 兑换 403 / 超频 429 / admin 连败 429 / 无码异路径。

## 批次 4 · v1.7.0 —— F2A + 后台扩权（预估 3h）

**A. Passkey 第二因子（指纹/面容）**
- 注册：口令登录后一键注册 Passkey（WebAuthn platform authenticator，Face ID/Touch ID）
- 登录：口令 → 指纹挑战 → 通过才进后台；验证用 WebCrypto（ES256），凭据存 D1
- 重置：仅通过 Cloudflare 层（我直连库）执行——设备丢失的兜底
- 若 Passkey 落地不顺，退路：TOTP（认证器 App 6 位码）

**B. 后台扩权（把「我能改的」都变成「你能调的」）**
- **规则设置**：格位数量、领取时限、认领上限（活跃/每日）、黄标阈值、月积分上限、找回奖励值（普通/高价值）、打赏上限
- **公告栏**：全站顶部公告（可开关、可写文案）——活动/失物高峰提示
- **物品管理**：全状态列表（含已出库）、编辑字段、下架/上架、换格位、看照片/存证
- **身份管理**：按学号搜索、改名/改班、重置 PIN、查看 TA 的物品/认领/积分
- **黄标处理**：Dismiss（resolved）按钮 + 一键放回公示板（已有）
- **审计日志**：admin_audit 只读查看
- **导出**：物品/认领/流水 CSV（运营盘点用）
- **看板**：实时统计（在架/已找回/流转中/活跃认领）
